# Operations

Before launch, choose structured logging/error monitoring, set alert ownership, document service dependencies and escalation contacts, and exclude secrets and personal content from logs. Define routine dependency/migration review, database capacity checks, account access review, retention/deletion, and incident communications.

For suspected compromise: restrict affected credentials/sessions, preserve relevant audit evidence, assess scope, restore from a known-good state if needed, notify affected parties/regulators as applicable, and record remediation. Establish and test the process with the operating team; this document alone is not an incident capability.
